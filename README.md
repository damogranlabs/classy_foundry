# classy_foundry

A FreeCAD workbench that provides a guided, visual GUI for
[classy_blocks](https://github.com/damogranlabs/classy_blocks), a Python
library for generating OpenFOAM `blockMeshDict` files.

This project is in early development. See [DESIGN.md](DESIGN.md) for
architecture and planning notes.
